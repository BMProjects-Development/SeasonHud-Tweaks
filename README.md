# SeasonHud Tweaks

[Русская версия](docs/ru.md)

SeasonHud Tweaks makes the season display require a calendar in your inventory, offhand, or a compatible accessory slot. The rule applies to the standalone HUD and supported minimaps.

Install the JAR for your Minecraft version and loader on the client alongside SeasonHud and a season mod that provides a calendar.
