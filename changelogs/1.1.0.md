# SeasonHud Tweaks 1.1.0

- Ported the calendar requirement to Forge, NeoForge, and Fabric across the supported SeasonHud releases from Minecraft 1.16.5 through 26.3.
- Use SeasonHud’s own inventory and accessory checks, with one active client mixin per SeasonHud generation. The Forge 1.17.1 port gates its three overlays through Forge’s render event. Forge 1.16.5 still supports SeasonHud 1.13.17.
- Removed the add-on’s mandatory Curios, JourneyMap, and Serene Seasons dependencies. SeasonHud handles the installed season provider and compatible accessory or minimap integrations.
- The Fabric 1.20.3 build was withdrawn because the upstream SeasonHud requires Forge Config API Port, which has no compatible release for that game version.
