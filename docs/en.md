# SeasonHud Tweaks player guide

[Русский](ru.md) · [Home](../README.md)

## Installation

1. Choose the file for your Minecraft version and loader on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/seasonhud-tweaks) or [GitHub Releases](https://github.com/BMProjects-Development/SeasonHud-Tweaks/releases).
2. Put it in the client’s `mods` folder with the matching SeasonHud release and its dependencies.
3. Install a compatible season mod. With Serene Seasons, use its Season Calendar. With Fabric Seasons, install Fabric Seasons Extras for its calendar.

The Forge 1.17.1 port uses the archived SeasonHud release from CurseForge. See the matching file’s dependency version in the release matrix.

## In a world

Place a calendar in your inventory or offhand to see the season. A calendar equipped in an accessory slot also works if your version of SeasonHud supports that slot. Store the calendar in a chest or drop it to hide the season display.

The tweak applies even when **Requires Calendar** is off in SeasonHud. SeasonHud still controls the selected season mod, the default behavior for season mods without a calendar, and the display settings. Turn on the overlay in SeasonHud or enable the season display in the minimap you use.

## Reporting a problem

Include your Minecraft version, loader, SeasonHud version, season mod, and minimap if applicable. For an accessory issue, include the accessory mod and the slot used. Attach the client’s `latest.log`. [Open an issue](https://github.com/BMProjects-Development/SeasonHud-Tweaks/issues).
